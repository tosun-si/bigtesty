<CardGrid stagger>
  <Card title="The real BigQuery engine" icon="approve-check">
    No emulator: the SQL behaves exactly as in production, scripts, `MERGE` and procedures included.
  </Card>
  <Card title="Given / When / Then" icon="document">
    Test files in YAML or JSON: load rows, run the SQL under test, assert on query results or table contents.
  </Card>
  <Card title="Isolated and ephemeral" icon="random">
    Each scenario of each run gets its own datasets, created and destroyed by BigTesty. Run in parallel, safely.
  </Card>
  <Card title="CLI and pytest" icon="seti:python">
    `bigtesty test` or `pytest`: one test per scenario, typed comparison and readable diffs.
  </Card>
</CardGrid>
